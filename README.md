# Istaknuti ratnici kroz istoriju

Responzivna, interaktivna web prezentacija o poznatim ratnicima kroz istoriju.
Fakultetski projekat iz predmeta Veb dizajn – Tehnički fakultet „Mihajlo Pupin“, Zrenjanin.


## Stranice
- **Početna** – uvod u temu
- **Ratnici** – pregled istaknutih ratnika
- **O nama** – informacije o projektu
- **Kontakt** – kontakt forma

## Tehnologije
HTML5, CSS3, JavaScript, jQuery

## Pokretanje
Otvoriti `index.html` u pretraživaču ili posetiti demo link.
